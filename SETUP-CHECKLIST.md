# Setup Checklist

## À faire de ton côté

1. Installer Node.js LTS

- Télécharger et installer Node.js LTS depuis le site officiel
- Vérifier ensuite :

```bash
node -v
npm -v
```

2. Installer les dépendances du projet

Dans le dossier du projet :

```bash
cd "/Users/jakeallimann/Documents/New project 2"
npm install
```

3. Lancer l'application

```bash
npm run dev
```

4. Ouvrir l'app

```text
http://localhost:3000
```
